# Ассистент для разбора событий входа

Ассистент помогает разобрать алерт о входе в аккаунт. Он выделяет факты из сообщения, определяет срочность и предлагает, что проверить дальше. Результат можно использовать для сортировки алертов перед ручным разбором.

## Вход и выход

На вход поступает текст одного алерта или фрагмент журнала о входе. На выходе получается JSON с типом события (`event_type`), приоритетом (`priority`), цитатами из алерта (`evidence`) и следующей проверкой (`next_check`).

Например, для алерта «Для user01 зафиксировано 5 неудачных попыток входа. Затем выполнен успешный вход в тот же аккаунт с нового IP» результат может выглядеть так.

```json
{
  "event_type": "suspicious_login",
  "priority": "medium",
  "evidence": [
    "Для user01 зафиксировано 5 неудачных попыток входа",
    "Затем выполнен успешный вход в тот же аккаунт с нового IP"
  ],
  "next_check": "Уточнить у владельца аккаунта, выполнял ли он этот вход."
}
```

## Обработка

1. Модель извлекает сведения об аккаунте, попытках входа и их результате. В ответ включает фрагменты алерта, которые подтверждают вывод.
2. По этим фактам модель определяет тип события, приоритет и следующую проверку.

В учебной версии `high` означает, что пользователь отрицает успешный вход. `medium` назначается подозрительному входу без подтверждённого объяснения или серии из трёх и более неудачных попыток по одному аккаунту. `low` означает ожидаемую активность, `unknown` используется при нехватке данных.

В One-shot обе операции выполняются за один запрос к модели `nvidia/nemotron-3.5-super-vl:free` через OpenRouter. В дальнейшем можно добавить поиск связанных событий и проверку IP по списку корпоративных адресов.

## Запуск

Нужен Python 3.9 или новее. Ключ OpenRouter задаётся в поле `OPENROUTER_API_KEY` файла `.env`. Сторонних зависимостей пока нет, поэтому `requirements.txt` пуст.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py "Для user01 зафиксировано 5 неудачных попыток входа. Затем выполнен успешный вход в тот же аккаунт с нового IP"
```

Скрипт проверяет структуру JSON, соответствие приоритета типу события и наличие цитат в исходном алерте. При ошибке печатает сообщение и завершает работу с кодом 1.
