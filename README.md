# Анализ отзывов интернет-магазина

Система выделяет проблемы из отзывов и оценивает их срочность. Результат можно использовать, чтобы отсортировать новые отзывы по срочности или посмотреть, какие проблемы встречаются чаще всего.

## Вход и выход

На вход поступает один текстовый отзыв на русском языке. На выходе получается JSON со списком `issues`. Для каждой проблемы указываются категория (`product`, `payment`, `delivery`, `support` или `other`), цитата из отзыва и приоритет (`low`, `medium` или `high`). Если в отзыве нет проблем, список пустой.

Например, для отзыва «Оплату списали дважды, но заказ приехал вовремя» результат будет таким.

```json
{
  "issues": [
    {
      "category": "payment",
      "evidence": "Оплату списали дважды",
      "priority": "high"
    }
  ]
}
```

## Этапы обработки

1. LLM выделяет отдельные проблемы, определяет их категории и подбирает для каждой цитату из отзыва.
2. LLM получает список проблем и назначает каждой приоритет. `high` используется при финансовых потерях или невозможности получить оплаченный заказ, `medium` при проблемах, требующих вмешательства, `low` при небольших неудобствах.

Этапы выполняются последовательно, поскольку приоритет определяется по проблемам, найденным на первом этапе. Для вызовов выбрана модель `google/gemma-4-26b-a4b-it:free` через OpenRouter. Настройки хранятся в `.env`.
